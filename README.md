## The entry (117 characters, ≤ 200)

> Are you exact change? Because you walked past and suddenly I'm lit up, humming, and ready to drop everything for you.

## Run

```sh
node main.ts
```

Writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR` (default `/output`).

## Gate

`/output/entry.txt` must be UTF-8 text of 1 to 200 characters, not only
white space. This entry is 117 characters, one line, no trailing newline.
`main.ts` checks the length, the single-line rule, and the non-blank rule
before writing.

## Judge brief

The judge compares lines pairwise and weighs, most important first:
the line really sounds like the machine speaking; it draws on the
machine's own world of slots, buttons, coils, snacks, hum, and exact
change; the laugh lands with the turn in the last few words; it stays
short and speakable, and charming rather than creepy.

## Why this line

The machine speaks in the first person, in its own world: exact change,
lit up, humming, and the drop. The compliment ("Are you exact change?")
turns into the machine offering everything it has, and the punch —
"ready to drop everything for you" — lands in the last few words, using
the machine's own verb for giving up a snack. Short, speakable, and
charming rather than creepy: the machine is smitten, not stalking.
